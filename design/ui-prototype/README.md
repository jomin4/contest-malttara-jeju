# UI 프로토타입

외부 디자인 도구로 만든 화면 시안. **화면 구성과 디자인 톤의 참고자료**이며 사양이 아니다. 기획(`docs/01_planning/기획문서_v0.md`)과 어긋나는 곳은 기획 다듬기에서 결정한다.

| 파일 | 내용 |
|---|---|
| `code.html` | STAGE 01 '자연어 의도 입력' 화면 1개 (단일 HTML, 41KB, Tailwind CDN) |
| `DESIGN.md` | 디자인 시스템 "Jeju Journey AI": 색상 토큰, 글꼴, 모서리, 간격, 컴포넌트 5종 정의 |
| `screens/stage01_의도입력.png` | code.html 렌더링 캡처 |

## 1. 화면 대응표 (기획 6단계 ↔ 프로토타입)

프로토타입 상단 탭은 4개(`01 의도 입력 / 02 AI 경로 분석 / 03 인터랙티브 탐색 / 04 취향 재설계`)이고, **실제로 그려진 화면은 01 하나**다. 탭 링크는 `href="#"`로 동작하지 않는다.

| 기획 단계 (v0 2.2) | 프로토타입 | 상태 | 비고 |
|---|---|---|---|
| 1 여행 설명 — 한 줄 입력 | 탭 01: 입력창, 추천 템플릿 칩, 큐레이션 코스 카드 3개, "AI 여행 경로 설계 시작" 버튼 | **있음** | 음성 입력 버튼은 기획에 없음 |
| 2 조건 확인 — 칩·선택상자 수정, 빈 항목 미반영 | 탭 01 하단 "AI 추출 파라미터 구조화" 카드 4개(여행 목적·일정 기간·취향·액티비티) | **부분** | 별도 단계가 아니라 같은 화면에 있음. 기획 항목(기간·여유·이동수단·동행·출발지·날짜·관심사) 중 여유·이동수단·동행이 없고, 빈 항목 표현이 없음 |
| 3 경로 만들기 (Batch A) — Tool 로그 실시간 | 버튼 클릭 시 뜨는 진행 모달(진행 원, 체크리스트 3줄) / 탭 02 | **모달만** | 모달 문구는 하드코딩. 탭 02 화면 없음 |
| 4 미리보기 — 게임 모드 / 목록 모드, 관심·꼭 갈래요·별로예요 | 탭 03 | **없음** | 하단 "풍경 카드 4개"의 하트 버튼이 장소 카드 반응의 실마리 정도 |
| 5 다시 짜기 (Batch B) | 탭 04 | **없음** | DESIGN.md에 "재설계 Diff" 컴포넌트 정의만 있음 |
| 6 최종 계획 — 근거, 변경 전후 비교, 인쇄 | 탭 04 | **없음** | DESIGN.md에 "최종 일정 요약" 컴포넌트 정의만 있음 |

DESIGN.md 컴포넌트 5종 → 기획 단계: 프롬프트 영역(1) · AI 추론 흐름 카드(3, 5) · 장소·타임라인 카드(4, 6) · 재설계 Diff(5, 6) · 최종 일정 요약(6). 게임 모드(SVG 지도·말·타이핑 입력·도착 카드)와 대시보드 통계 차트는 **정의 자체가 없다**.

## 3. 구현 시 처리 (B 트랙)

외부 의존성 — 센터 PC가 오프라인이면 화면이 깨진다(D7은 데이터·지도·정적 파일 모두 로컬).

| 의존 | 위치 | 처리 |
|---|---|---|
| Tailwind CDN (`cdn.tailwindcss.com`, 브라우저 런타임 컴파일) | `<head>` + 인라인 `tailwind.config` | React 빌드에 Tailwind를 설치하고 `tailwind.config`의 색상·글꼴·간격 토큰을 그대로 옮김 |
| Google Fonts: Inter, Plus Jakarta Sans | `<head>` | 두 글꼴 모두 **한글 글리프 없음** → 한글 글꼴(오픈 라이선스) 선정, 파일 동봉. 라이선스는 명시 사항에 기록 |
| Material Symbols (Google Fonts) | 아이콘 전반 | 쓰는 아이콘만 SVG로 동봉하거나 글꼴 파일 로컬화 (Apache 2.0, 명시) |
| `lh3.googleusercontent.com` 이미지 5개 (풍경 4, 프로필 1) | 카드·헤더 | 출처·라이선스 불명 → 사용하지 않음. 장소 데이터 기반 일러스트/지도/텍스트 카드로 대체 |

재사용할 것
- DESIGN.md의 색상 토큰(primary `#005c55`/`#0F766E` 계열 청록, secondary `#9d4300` 계열 주황), 타이포 스케일, 모서리·간격 → 그대로 디자인 토큰으로
- 화면 레이아웃: 큰 입력창 + 템플릿 칩 + 파라미터 카드 그리드 → 1·2단계 화면 골격
- 인라인 스크립트 동작(`setPrompt`, `selectPreset`)은 단순하므로 React 상태로 다시 작성

새로 그려야 할 화면: 3(Tool 로그·진행), 4(게임 모드: SVG 지도+말+타이핑 / 목록 모드), 5(재설계 Diff), 6(최종 계획·근거 패널·인쇄), 대시보드 통계 차트.
