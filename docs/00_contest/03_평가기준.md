# 평가 기준

최종 점수 = **내부 전문가 평가 70% + ELO 기반 참가팀 상호 평가 30%**

## 참가팀 상호 평가 (30%)

- 기간: 11/23(월) 12:00 ~ 11/27(금) 10:00, 최종 제출을 완료한 팀 대상
- 방식: 평가자가 두 산출물을 비교해 더 나은 쪽에 투표 → Elo 산식으로 점수화
- 본인(팀) 제출물은 투표 화면에 나오지 않음
- **최소 투표 횟수에 못 미치면 내 투표와 득표가 모두 반영되지 않음 (No Vote, No Gain)**
- 이 단계에서는 **기획서만 공개**된다 → 기획서 자체의 완성도가 30%를 좌우

## 주제 선정 때 활용할 관점

- 기술성(25)과 편의성(25)이 절반 → "센터 PC에서 비전문가가 안정적으로 쓸 수 있는가"가 핵심

- 재현성(15) → 설치 절차·매뉴얼·결과 근거를 처음부터 고려
