## 3. 대회 규칙과 유의사항

### 제출 및 AI 도구
- 생성형 AI·AI 개발 도구 사용 가능
- 최종 제출 시 **사용 AI 모델, AI 활용 범위, 외부 API·서비스, 외부 데이터, 오픈소스 및 외부 코드**를 명시해야 함

### 외부 데이터 및 API
- 필수 데이터 외 공개 데이터·외부 API는 적법하게 쓸 수 있는 경우에만 사용, 출처 명확히 표기
- 외부 서비스 의존성은 개발·탑재 계획과 실행 매뉴얼에 명시
- 제주데이터허브 등 **데이터 API의 실제 키는 제출물에 넣지 않고**, 키 발급·설정 방법을 실행 매뉴얼에 작성
- 외부 LLM 등 **AI API는 평가용 키를 참가자가 준비하고 평가 비용도 참가자 부담**
- 평가용 외부 AI API 키는 ZIP 안 실행환경·매뉴얼에 포함해 제출 가능. 상호평가 단계에는 기획서만 공개되고, ZIP은 심사위원 평가에 쓰임
- 평가용 키는 사용 한도를 걸어 제출할 수 있으며, 평가 기간 후 삭제·폐기

### 개인정보 및 보안
- 개인정보·금융정보·인증정보·API 키 등 민감정보를 코드·발표자료·영상에 넣지 말 것 (평가용 AI 키만 위 예외)
- 외부 서비스 이용약관·보안 기준 준수
- 분석 결과물에 개인정보가 드러나지 않게 하고, 필요하면 가명처리

### 저작권 및 부정행위
- 데이터·이미지·코드·모델은 적법하게 사용할 수 있어야 함
- 타 공모전 수상작이나 이미 공개·상용화된 결과물을 그대로 제출하는 것은 제한
- 표절·저작권 침해·허위 기재 등이 사후 확인되면 평가 제외 또는 수상 취소 가능

### 결과물 검증
- 운영진이 정상 작동·사실관계 확인을 위해 코드 실행을 요청할 수 있음
- 실행환경, 모델, 데이터, API 이용 내역 등 추가 자료 요청 가능
- 제출물이 발표·시연 내용과 현저히 다르면 평가·수상에 반영

### 결과물 소유권
- 모든 결과물은 제주빅데이터센터에 소속되며, 시상작은 제작자(팀) 이름으로 센터에서 제공될 수 있음
