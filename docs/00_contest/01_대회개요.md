# 대회 개요

- **대회명**: 제주 AI·빅데이터 활용 AI Agent 개발 챌린지
- **주최**: 제주테크노파크 / 운영 플랫폼: DAKER(데이콘)
- **상금**: 총 500만 원 — 대상 1팀 300만, 최우수 1팀 100만, 우수 2팀 각 50만

## 배경과 목적

제주빅데이터센터·제주데이터허브가 보유한 데이터와 AI 도구로 **데이터 탐색·분석을 자동화하는 AI Agent**를 발굴하는 대회.
IT 비전문가인 도민도 제주빅데이터센터에서 직접 실행·활용할 수 있도록, **데이터 탐색부터 분석 결과 제공까지 수행하는 서비스**를 만드는 것이 요구사항.

## 주제

제주빅데이터센터 또는 제주데이터허브 데이터를 **1종 이상** 활용해 분석 주제를 **자유롭게** 선정하고, 그 주제에 맞는 AI Agent를 구현한다.

## 참가

- 자격: 일반인·학생 등 누구나
- 개인 또는 팀(**최대 5인**). 동일인은 개인·복수 팀에 중복 등록 불가
- 팀빌딩 페이지에서 팀을 꾸렸다면, 제출 전에 팀장이 대회 안내 페이지에서 "팀으로 전환"을 완료해야 함
- 공식 문의는 대회 게시판으로만 답변 (다른 채널은 지연·미답변 가능)
