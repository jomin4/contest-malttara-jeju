# 02 기획서 (대회 제출용)

superpowers 설계 문서(`docs/superpowers/specs/`)와 별개로, **대회 양식에 맞춘 제출용 기획서**를 여기서 작성한다.
상호평가(30%)에서는 이 기획서만 공개되므로 기획서만 읽어도 서비스와 Agent가 이해되게 쓴다.

- 분량: **15쪽 이내**
- 파일: `proposal.md` (작성) → 최종 PDF로 변환해 제출

## 필수 구성 체크리스트 (원문 항목)
- [ ] **구현목표**: 분석 주제, AI를 활용한 데이터 분석 목표
- [ ] **서비스 제안**: 데이터 활용 개요, 핵심 기능, 편의성, 분석데이터 활용 방안
- [ ] **Agent 개발 구성**: 참여자 역할·목표·Workflow, 사용 모델, Tool/API, 판단 및 자율 수행 범위
- [ ] **데이터 활용 계획**: 필수 데이터명·출처·활용 항목, 수집·전처리 방법, 이용조건
- [ ] **개발·탑재 계획**: 구현 범위, 기술 환경, UI 구성, 센터 실행환경(i7-8700 / GTX 1060 / RAM 32GB / VRAM 3GB)과 외부 서비스 의존성

## 작성 팁
- 평가항목(주제 15 / 데이터 20 / 기술성 25 / 편의성 25 / 재현성 15)마다 근거가 되는 문단이 있는지 확인
- 데이터는 ID·데이터명·출처(제주데이터허브 상세 URL)를 표로 명시
- Agent의 판단 지점과 자율 수행 범위, 실패 시 대응(폴백)을 그림 1장으로
