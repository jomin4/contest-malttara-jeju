# 말따라 제주 — 데이터 활용 명세

- 작성: 2026-11-19 (A 트랙)
- 수치 근거: 동봉 DB `data/db/malttara.sqlite`(`meta.data_version = 2026-11-19`, 2026-11-19 14:44 빌드)의 `places`·`emd_stats`·`sight_visits`·`data_sources`·`meta.build_stats`를 직접 조회한 값. 원본 확인 내용은 `data/cards/{ID}_*.md`의 '분석 결과'.
  - 카드의 '분석 결과' 일부 매칭 수(예: 장소 4024곳, 811 24곳)는 **11/17 첫 빌드** 기준이다. 그 뒤 정제 규칙이 강화되어(같은 이름 병합 2km, 분류 없는 1349 기록 추천 제외 등, `docs/01_planning/decisions.md`) 현재 DB 값과 다르다. **이 문서는 현재 DB 값을 따른다.**
  - 데이터를 다시 빌드하면 수치가 바뀔 수 있다. 제출 직전 빌드로 다시 확인한다(9장 쿼리).
- 원칙 (기획문서_v0 1.3): 수치는 Tool(코드)이 DB에서 계산한 값만 쓴다. **지역 단위 통계(563)는 읍면동 지표로만 표시하고 개별 장소의 속성으로 표시하지 않는다.** 직선거리를 이동시간으로 표현하지 않는다.

## 5. 에이전트에서의 사용 (점수·Tool)

```
점수 = w1 × 관심사 + w2 × 분산(563) + w3 × 한적(1208) + w4 × 인지도(1349 기록 수)
현재 가중치(config/settings.json, 2026-11-19): 기본 (0.5, 0.15, 0.15, 0.2) · 한적함 요청 시 (0.4, 0.25, 0.25, 0.1)
```

| 항 | 데이터 | 계산 |
|---|---|---|
| 관심사 | 분류(TourAPI·811·812·784·858·키워드) | 장소 분류가 관심사 분류 목록(`config/interests.json`)에 있으면 1, 아니면 0. 관심사 미입력이면 분류 있는 장소 1 |
| 분산 | 563 | 1 − 읍면동 visit_ratio 백분위. 지표 없으면 0.5 |
| 한적 | 1208 | 1 − quiet_count 백분위. 0건·없음이면 0.5 |
| 인지도 | 1349 | 같은 이름 기록 수의 백분위. 하루마다 관심사 일치 + 기록 최다 장소 1곳을 대표지로 넣음 |

| Tool (`src/malttara/tools/`) | 쓰는 데이터 |
|---|---|
| `search_places`, `score_places` | places(1349·TourAPI), emd_stats(563), quiet_count(1208), popularity(1349) |
| `get_region_data` | emd_stats(563) |
| `analyze_tourism` | sight_visits(189·190) |
| `check_data_quality` | 분류·지표 결측 수 집계 → 실행 로그와 결과 `quality` |
| `create_itinerary`, `calculate_route`, `validate_itinerary` | 장소 좌표(하버사인 직선거리), 권역 |
| `explain_decisions`, `export_travel_plan` | 각 지표의 source_id·기간(`data_sources.period_actual`)을 근거 문장·인쇄물 출처 표에 표시 |

- 한적함 요청("조용한·한적한·덜 붐비는")은 가중치를 바꿔 563·1208 지표가 순위를 더 크게 움직이게 한다.
- 지표가 없으면 값을 지어내지 않고 `missing: true`, 값 `null`로 내보낸다(인수 테스트 5·9).

## 6. 재현성

- 같은 DB(`data_version`) + 같은 설정(`config/`) + 같은 조건 → 같은 순위·같은 일정(동점은 `place_id` 순). 인수 테스트 2(`tests/test_acceptance.py`).
- 데이터 지표가 바뀌면 순위가 바뀐다(인수 테스트 4: 한 장소의 반경 체류 수를 최댓값보다 크게 → 한적함 요청 순위 하락).
- 출처·기준 시점은 모든 장소 지표(`source_id`, `period`)와 인쇄물 출처 표에 나온다(인수 테스트 9).

## 7. 한계

- **1349는 이용자가 여행 일정에 입력한 장소 기록**이다. 같은 장소가 여러 좌표로 반복되고(카드 점검 시 '성산일출봉'만 43건), 좌표·지번주소 오류, 숙소·식사 같은 비장소 이름이 섞여 있다. 정제(같은 이름 2km 병합, 좌표 오류 이동 88곳·제외 16곳, 같은 권역 중복 108곳 제외, 분류 없는 기록 추천 제외)로 줄였지만 완전히 없앨 수는 없다. 인지도 항도 "여행자 기록 수"이지 실제 방문객 수가 아니다.
- **1208은 2021년 7~12월 토요일 렌터카 표본**이다. 평일·대중교통·도보 여행자·현재 상황을 반영하지 않는다. "현재 혼잡도"로 표현하지 않는다.
- **563은 2022-09에서 끝나는 내국인 유동인구**다. 외국인·2022-10 이후는 반영되지 않는다. 읍면동 단위 통계이므로 장소의 속성으로 쓰지 않는다.
- 189·190은 관광지 50곳 중 29곳만 장소와 연결되어 점수에 넣지 않고 근거 차트로만 쓴다.
- 개요(overview)는 추천 대상의 26.8%(371곳)에만 있다. 개요가 없으면 화면에 비워 둔다.
- 허브 보조 데이터(811·812·784·858)의 분류 매칭은 수 곳에 그친다. 분류 대부분은 TourAPI와 이름 키워드에서 왔고, 키워드 분류는 이름만 보고 붙이므로 틀릴 수 있다.
- 부속섬(우도·추자 등)은 배 이동을 직선거리로 검증할 수 없어 제외했다.
- 거리는 직선이며 도로·대중교통·이동시간을 반영하지 않는다.
- 데이터별 공공누리 유형 등 세부 이용조건은 일부 **미확인**이다(2장 표의 '미확인' 항목).
