# 실행 환경 점검 (B 화면 기준) — 2026-11-19

센터 PC(Windows 11, i7-8700, GTX 1060, RAM 32GB, VRAM 3GB, 오프라인 가능성)에서 화면이 문제없이 동작하는지 점검한 기록이다.
Windows 실기에서만 확인할 수 있는 항목은 2장 체크리스트로 남긴다. 설치·실행 절차는 `manual_run.md`.
