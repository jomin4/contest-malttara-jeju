# 비용을 고려한 설계 — 원칙과 실측

> 2026-11-19 · 모델 Claude Haiku 5.5(`claude-haiku-5-5`) · 단가 입력 $0.10 / 출력 $0.50 (100만 토큰당, 프롬프트 10만 토큰 이하)
> 수치는 아래 4장 측정에서 DB `llm_usage` 표에 기록된 실제 토큰으로 계산했다(재현: `PYTHONPATH=src python -m malttara.agent.usage`).

## 1. 설계 원칙

| 원칙 | 구현 | 효과 |
|---|---|---|
| **LLM은 판단에만** | 조건 해석·작업 계획·수정 행동·유지/교체·요약 다듬기 5곳만 호출. 점수·거리·검증·적용은 코드 | 계산에 토큰을 쓰지 않음. 수치 오류도 없음(원칙 1) |
| **실행 중 데이터 API 0회** | 허브·TourAPI 데이터는 빌드 때 SQLite로 가공해 동봉 | 데이터 API 호출 비용·지연 0 |
| **가장 싼 모델 + 짧은 출력** | Claude Haiku 5.5, 생각(thinking) 끔, effort `low`, `max_tokens` 1,024. 출력은 장소 ID·정해진 값(enum)만, 숫자 필드 없음 | 호출당 출력 수십~수백 토큰 |
| **안 불러도 되면 안 부른다** | 키 없음·오프라인·인젝션 의심·분당 상한 초과 → 규칙 모드(비용 0원, 전 기능 동작). 같은 판단은 실패해도 재시도하지 않고 규칙으로 | 장애·남용 때 비용이 늘지 않음 |
| **남용 상한** | 서버 전체 분당 LLM 호출 30회(`config/security.json`), 평가용 키는 콘솔 지출 한도 설정 | 키오스크 연타·자동 요청에도 비용 상한 |
| **실측 기록** | 판단 지점마다 입력·출력 토큰을 `llm_usage`에 저장, 단가로 비용 집계(단가 없는 모델은 비용 미표시) | "1회에 얼마"를 추정이 아닌 실측으로 제시 |
| **SDK 없이 표준 라이브러리** | `urllib`으로 Anthropic Messages API 직접 호출 | 센터 PC에 패키지 설치 불필요(D17) |

## 2. 판단 지점별 실측 (호출 1회 평균)

| 판단 지점 | 호출 수(측정) | 입력 토큰 | 출력 토큰 | 비용(USD) |
|---|---|---|---|---|
| 조건 해석 `parse_goal` | 2 | 820 | 180 | 0.00017 |
| 작업 계획 `plan_tasks` | 2 | 965 | 413 | 0.00030 |
| 수정 행동 `revise` (오류 주입 시연) | 2 | 1,070 | 35 | 0.00012 |
| 유지·교체 `redesign` | 1 | 692 | 165 | 0.00015 |
| 요약 다듬기 `polish_summary` | 3 | 519 | 193 | 0.00015 |

## 3. 방문객 1명(한 번의 체험) 비용

| 흐름 | LLM 호출 | 비용(USD) | 응답 시간(측정) |
|---|---|---|---|
| 조건 해석 + 경로 만들기(Batch A) | 3 | 약 0.0006 | 조건 1.3초 + 경로 5.6초 |
| + 오류 주입 시연(수정 2회 포함) | 5 | 약 0.0009 | 경로 9.1초 |
| + 미리보기 반응으로 다시 짜기(Batch B) | +2 | +0.0003 | 4.1초 |
| **전체 체험(시연 포함)** | **약 7** | **약 0.0012** | — |

→ 방문객 **1,000명이 전체 체험을 해도 약 $1.2** (같은 단가 기준). 규칙 모드는 0원.

## 4. 측정 방법

- 2026-11-19, 로컬 서버(`run.py`) + 실제 DB(Release `data-2026-11-19`) + `.env`의 Claude Haiku 5.5 키.
- 입력: "2박 3일 동안 바다를 보며 여유롭게 쉬고, 현지 음식도 먹고 싶어요" → Batch A(일반, 오류 주입) → 반응(꼭 갈래요 1, 별로예요 1) → Batch B.
- 토큰은 API 응답의 `usage.input_tokens`·`output_tokens`를 그대로 기록. 비용 = 토큰 × 단가(`config/settings.json` `llm.price_usd_per_mtok`).
- 입력 문장·조건에 따라 토큰은 달라진다. 위 값은 예시 1건의 실측이며 평균이 아니다.

## 5. 한계

- 단가는 2026-11 기준 공개 가격으로 설정 파일에 적었다. 가격이 바뀌면 설정만 고치면 된다.
- 원화 환산은 환율에 따라 달라 표시하지 않는다.

## 부록. 기획서 문단 초안 (3.3 사용 모델 또는 5.4 뒤)

**비용을 고려한 설계** — LLM은 판단 5곳에서만 쓰고, 점수·거리·검증은 코드가, 데이터는 미리 가공한 DB가 맡아 실행 중 데이터 API 호출이 없습니다. 가장 저렴한 Claude Haiku 5.5를 생각(thinking) 없이 짧은 출력(장소 ID·정해진 값)으로만 호출하고, 키가 없거나 장애·남용(분당 30회 초과)·인젝션 의심이면 규칙 모드(0원)로 같은 기능을 제공합니다. 판단마다 실제 토큰을 기록해 측정한 결과, 방문객 1명의 전체 체험(경로 생성·오류 수정 시연·다시 짜기, LLM 약 7회)은 약 $0.0012로, 1,000명이 써도 약 $1.2입니다.
