# 요일별 전기자동차 충전 이력

## 요약

- 교통, 안전 분야, 제공형태 **API**, 수집기간(메타) 2021-01-01 ~ 2022-06-30
- 단위(추정): 공간 정류소 · 시간 월 / 연결 키(추정): 날짜(일), 연월, 연도, 정류소
- 제공처: 제주특별자치도 미래모빌리티과 / 조회수 687 / 등록 2022-12-02 · 수정 2022-12-02

### 원문 설명

제주특별자치도와 환경부(한국환경공단)에서 운영하는 전기차 충전기의 충전 이력 데이터를 요일별로 취합한 데이터 입니다.
전기차가 얼마나 충전 했는지, 충전 시간은 얼마나 되는지, 충전량은 얼마나 되는지 확인할 수 있습니다.
충전 횟수는 합계, 충전 시간, 충전량, 충전 금액은 평균으로 계산 되었습니다.
- 데이터 제공처: 제주특별자치도 저탄소정책과

## 수집 방법

- **Open API** (GET, JSON), 일일 호출 한도 1000회
- 호출: `https://open.jejudatahub.net/api/proxy/71111t11a161tb1Da611Daab2a91912a/{프로젝트키}?파라미터`
