## 수집 방법

- **Open API** (GET, JSON), 일일 호출 한도 1000회
- 호출: `https://open.jejudatahub.net/api/proxy/617bt7b7ttb1Datab7a7ttD6tbt7611t/{프로젝트키}?파라미터`
- 사전 조건: 로그인 → 프로젝트에 이 데이터 담기 → 프로젝트키 (guides/how-to-collect.md)

**요청 변수**

| 이름 | 설명 | 타입 | 필수 | 예시 |
|---|---|---|---|---|
| startDate | 분석 시작일(필수) | string | Y | YYYYMMDD |
| endDate | 분석 종료일(필수) | string | Y | YYYYMMDD |
| moveType | 탑승구분 | string | N | 승차, 환승 |
| priceType | 요금제 | string | N | 일반, 청소년, 어린이, 기타 |
| payType | 지불방법 | string | N | 카드, 현금 |

**응답 필드**

| 이름 | 설명 | 예시 |
