## 수집 방법

- **Open API** (GET, JSON), 일일 호출 한도 1000회
- 호출: `https://open.jejudatahub.net/api/proxy/b6000b0ta01tDDaat00btaaat1Dtb101/{프로젝트키}?파라미터`
- 사전 조건: 로그인 → 프로젝트에 이 데이터 담기 → 프로젝트키 (guides/how-to-collect.md)

**요청 변수**

| 이름 | 설명 | 타입 | 필수 | 예시 |
|---|---|---|---|---|
| startDate | 분석 시작일(필수) | string | Y | YYYYMM |
| endDate | 분석 종료일(필수) | string | Y | YYYYMM |
| marketType | 업종 | string | N | 렌 트 카, 면 세 점, 특급 호텔, 여관/기타숙박업 |
