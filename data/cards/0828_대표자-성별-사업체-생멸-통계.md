# 대표자 성별 사업체 생멸 통계

## 요약

- 소비, 경제 분야, 제공형태 **파일**, 수집기간(메타) 2018-01-01 ~ 2023-12-31
- 단위(추정): 시간 연 / 연결 키(추정): 연도, 성별·연령
- 제공처: 제주데이터허브 / 조회수 123 / 등록 2021-09-13 · 수정 2025-09-30

### 원문 설명

- 2018년, 2019년, 2020, 2021년의 대표자 성별 사업체 생멸 수 통계를 제공합니다.
- 신생사업체는 전년에는 존재하지 않았으나 기준년에는 활동 중인 사업체이고, 소멸사업체는 전년에는 활동 중이었으나 기준년에는 존재하지 않는 사업체입니다.
- 2018년에는 활동사업체, 소멸사업체 통계만 제공되고, 2019년에는 활동사업체, 신생사업체 통계만 제공됩니다.
- 단위: 개
-「-」는 해당 값 없음,「*」은 5이하 해당숫자를 의미합니다.
- 데이터 제공처: KOSIS 국가통계포털
