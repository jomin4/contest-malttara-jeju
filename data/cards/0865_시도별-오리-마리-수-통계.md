# 시도별 오리 마리 수 통계

## 요약

- 농축수산 분야, 제공형태 **API**, 수집기간(메타) 2012-01-01 ~ 2025-06-30
- 단위(추정): 공간 시도 · 시간 분기 / 연결 키(추정): 연도
- 제공처: 제주데이터허브 / 조회수 108 / 등록 2021-10-21 · 수정 2025-10-02

### 원문 설명

- 분기·시도·오리 구분별 오리 마리 수 통계를 제공합니다.
- 분기 컬럼에서 앞의 4자리는 연도를 의미하고, 나머지 2자리는 분기를 의미합니다.
- 오리 구분은 용도와 월령에 따른 구분으로 '종오리-6개월미만', '종오리-6개월이상', '육용오리-45일미만', '육용오리-45일이상'으로 구분되어있습니다.
- 데이터 제공처: KOSIS 국가통계포털

## 수집 방법

- **Open API** (GET, JSON), 일일 호출 한도 1000회
- 호출: `https://open.jejudatahub.net/api/proxy/ba5aatb16a5a8atatb6tt6158taa1aaa/{프로젝트키}?파라미터`
- 사전 조건: 로그인 → 프로젝트에 이 데이터 담기 → 프로젝트키 (guides/how-to-collect.md)

| duckType | 오리 구분 | string | N | 종오리-6개월미만, 종오리-6개월이상, 육용오리-45일미만, 육용오리-45일이상 |
