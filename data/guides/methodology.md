# 조사 방법과 한계

## 수집

- 일시: 2026-11-15, 대상: jejudatahub.net 공개 데이터 전체 1,259건 (누락 0건)
- 목록: `GET https://jejudatahub.net/api/data?...&length=2000` — 사이트 데이터 목록 화면이 쓰는 내부 API, 인증 불필요
- 상세: `GET https://jejudatahub.net/api/data/view?id={ID}&userId=` — 태그·미리보기(csvData) 포함. 조회수가 오르지 않도록 `viewCount` 파라미터는 붙이지 않음
- 속도: 동시 3건, 요청 간 0.15초. 실패분은 재시도해 전부 수집
- 결과: `catalog/catalog_raw.json` (필드 정리본). 같은 방식의 스크립트: `scripts/fetch_catalog.py`
- 공식 문서가 없는 내부 API이므로 하루 1회 수준으로만 호출한다

## 가공 규칙 (scripts/build_catalog.py)

| 필드 | 규칙 |
|---|---|
| `type` | dataApi / dataFile / dataLink 유무 (API·파일·링크, 복수 가능) |
| `end_year` | 수집 종료일 연도. `9999` → "계속(미정)", 빈 값 → "미기재" |
| `spatial` | 컬럼명·제목에서 좌표 → 격자 → 읍면동 → 정류소 → 관광지 → 시군구 → 시도 순으로 먼저 맞는 것 (추정) |
| `temporal` | 자동갱신 주기가 있으면 그 값, 아니면 컬럼명에서 시간 → 일 → 월 → 분기 → 연 순. '데이터기준일자' 같은 스냅샷 날짜는 제외, 해당 없으면 "시점(스냅샷)" (추정) |
| `join_keys` | 컬럼명·API 필드명에서 날짜·연월·연도·읍면동·시군구·정류소·노선·관광지명·좌표·주소·업종·국가·품종·성별연령 패턴 (추정) |
| `themes` | 제목·태그·설명 앞부분 키워드로 16개 주제군 분류, 복수 가능 (추정) |
| `series` | 제목 패턴: `_무장애여행(위치/주변/일반)정보`, `_주제N_`(분석 주제 매쉬업), `렌터카 체류 빈도` |

## 알려진 한계

1. **기간**: `period_meta`는 사이트 기재값. 일 단위 API 다수가 시작일만 적혀 있음 → 실제 범위는 탐색 호출 필요
2. **자동갱신 표시**: 480건이 자동갱신으로 표시되나 교육·행정 등 링크형 다수 포함
3. **추정 필드**: spatial·temporal·join_keys·themes는 규칙 기반 추정이라 오분류가 있을 수 있음 (예: 운영시간 컬럼이 '시간' 단위로 잡힘)
4. **미리보기**: 사이트 미리보기 최대 5행만 반영. 실제 행 수·결측·분포는 원본 적재 후 '분석 결과'에서 확인
5. **API 응답 형식**: 페이지 처리·최대 행 수는 프로젝트키로 호출해 봐야 확인 가능
6. **파일 인코딩**: CP949·UTF-8 혼재
7. **최신성**: 종료 연도가 2019~2021년인 데이터가 가장 많다. 2025년까지 이어지는 것은 버스 대용량 파일, 농산물 거래 API, 업종별 카드 이용, 입도객 API 등 일부
